# Online Food Delivery Analysis
This project explored key patterns in online food delivery using a simulated dataset. It showed how factors like delivery time, food price, and customer ratings could influence satisfaction levels and delivery performance. Even though the data is randomly generated, the analysis helped practice real-world techniques such as data collection, visualization, and trend analysis.

➔ Analyzed online food delivery data using Python to identify customer trends using Jupyter Notebook. 

➔ Created visualizations and generated insights for business decision-making that improve the progress.

# Technologies Used
* Python
* NumPy
* Pandas
* matplotlib
* seaborn
* CSV Dataset

# Future Improvement
In future versions of this project, the dataset could be made more realistic by introducing time-based trends, customer behavior patterns, or location-based demand. Machine learning models could also be applied for predicting delivery delays or recommending food based on customer preferences, adding more depth to the analysis.
