# Online Food Delivery Analysis
This project explored key patterns in online food delivery using a simulated dataset. It showed how factors like delivery time, food price, and customer ratings could influence satisfaction levels and delivery performance. Even though the data is randomly generated, the analysis helped practice real-world techniques such as data cleaning, visualization, and trend analysis.

➔ Analyzed online food delivery data using Python to identify customer trends using Jupyter Notebook. 

➔ Created visualizations and generated insights for business decision-making that improve the progress.

# Technologies Used
* Python
* NumPy
* Pandas
* matplotlib
* seaborn
* CSV Dataset
